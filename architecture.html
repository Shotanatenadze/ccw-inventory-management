Data Flow Architecture

1. User Interaction → User selects filters in FilterBar component
2. State Update → useFilters() composable updates reactive state
3. API Call → Vue component calls api.js method with filters
4. HTTP Request → Axios sends GET request with query parameters
5. FastAPI Processing → apply_filters() and filter_by_month() process data
6. Data Validation → Pydantic models validate and serialize response
7. Vue Update → Reactive refs update, computed properties recalculate
8. UI Re-render → Template updates with new data automatically

Key Architecture Patterns

📱 Frontend Patterns

  • Composition API: All components use Vue 3 Composition API with setup() function
  • Composables: Shared logic extracted into reusable composables (useFilters, useAuth, useI18n)
  • Reactive State: Centralized filter state using reactive refs and computed properties
  • Component Communication: Props down, events up pattern with global state for filters

🔙 Backend Patterns

  • FastAPI: Modern async Python web framework with automatic API docs
  • Pydantic Models: Type validation and serialization for all API responses
  • In-Memory Data: JSON files loaded at startup for fast read operations
  • Functional Filtering: Pure functions for data filtering with no side effects

📊 Data Patterns

  • JSON Storage: 7 JSON files containing mock data for different entities
  • No Database: Simplified demo approach with file-based storage
  • Restart to Refresh: Data changes require server restart to reload from files
  • In-Memory Processing: All filtering and aggregation happens in Python memory

Development Workflow

🚀 Getting Started

Backend: cd server && uv run python main.py

Frontend: cd client && npm install && npm run dev

Access: Frontend at http://localhost:3000, API docs at http://localhost:8001/docs

🔄 Typical Development Flow

  1. Start both servers (backend port 8001, frontend port 3000)
  2. Make changes to Vue components or FastAPI endpoints
  3. Hot reload automatically reflects changes (Vite + FastAPI auto-reload)
  4. Test API endpoints using FastAPI docs interface
  5. Update JSON data files and restart backend to see data changes

📁 Key Files to Modify

  • Add Views: Create .vue files in client/src/views/ and update router in main.js
  • Add API Endpoints: Add functions to server/main.py with Pydantic models
  • Modify Data: Edit JSON files in server/data/ and restart backend
  • Add Filters: Update useFilters.js composable and filter functions in main.py
